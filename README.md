# Word by Word

Інтерактивний рідер для вивчення англійської через читання — з перекладом українською.

## Можливості

- 24 оригінальні історії рівнів A1–B2 із кількома абзацами в кожній;
- переклад кожного слова та заголовків за кліком;
- зелена підсвітка слова при наведенні без постійних підкреслень;
- подвійний клік і клік на порожньому місці закривають картку перекладу;
- картка перекладу з’являється поряд з обраним словом;
- особистий лічильник вивчених слів;
- завантаження TXT, MD і FB2 для читання; EPUB позначається на обробку.

## Запуск

Потрібен Node.js 22 або новіший.

```bash
npm install
npm run dev
```

Для перевірки збірки:

```bash
npm run build
```

Для частих і неоднозначних слів використовується вбудований словник. Решта перекладів спершу запитуються через DeepL, а MyMemory використовується як резервний варіант.
