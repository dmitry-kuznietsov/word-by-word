# Слово

Интерактивная читалка для изучения английского и русского языков.

## Что умеет

- 24 встроенных оригинальных истории уровней A1–B2 с несколькими абзацами в каждом тексте;
- перевод каждого слова в тексте по нажатию;
- зелёная подсветка слова при наведении без постоянных подчёркиваний;
- двойной клик закрывает карточку перевода;
- карточка перевода появляется рядом с выбранным словом;
- личный счётчик изученных слов;
- загрузка TXT, MD и FB2 для чтения; EPUB отмечается на обработку.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Для проверки сборки:

```bash
npm run build
```

Для частых и неоднозначных слов используется встроенный словарь; остальные переводы запрашиваются через MyMemory Translation API. Для стабильного рабочего продукта с большой нагрузкой рекомендуется заменить внешний источник на собственный переводческий сервис.
