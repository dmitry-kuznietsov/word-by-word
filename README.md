# Слово

Интерактивная читалка для изучения английского и русского языков.

## Что умеет

- 8 встроенных оригинальных историй уровней A1–B2;
- перевод каждого слова в тексте по нажатию;
- зелёная подсветка слова при наведении;
- двойной клик закрывает карточку перевода;
- личный счётчик изученных слов;
- загрузка TXT, MD и FB2 для чтения; EPUB отмечается на обработку.

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev
```

Для проверки сборки:

```bash
npm run build
```

Переводы запрашиваются через MyMemory Translation API. Для стабильного рабочего продукта с большой нагрузкой рекомендуется заменить этот источник на собственный переводческий сервис.
